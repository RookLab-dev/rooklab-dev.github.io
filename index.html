Claude

Claude writes the experiment. The engine produces the numbers.

We plan to use Claude to turn a researcher's idea into a structured, reproducible experiment, and to explain the results in plain language.

  • A language model never produces results or places orders.
  • Calculations, backtests and statistics stay in deterministic Python and Rust.
  • Humans review generated strategy code before it runs.
  • Execution stays on testnet until risk controls are proven.

API credits would fund building and evaluating the first version of this interface, and we will publish what worked and what did not.

1
Describe a hypothesisPlain-language idea from the researcher.
2
Claude drafts the experiment specUniverse, signal, parameters, validation method.
3
Deterministic engine runs itBacktest, walk-forward and Monte Carlo in code.
4
Claude explains the outputCites the engine's numbers and flags overfitting signs.

Hyper-Engine

A Python algorithmic trading framework built for Hyperliquid. It covers market data, strategy development, backtesting, risk management and testnet execution.

Not yet a commercial product. Execution runs on testnet only.

# pipeline
data → hyperliquid.ingest()
signals → indicators.from_scratch()
test → backtest("walk_forward")
validate → monte_carlo(trades)
risk → limits.daily_loss()
execute → testnet.sign_and_send()
