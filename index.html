Engineering focus

What we work on

Four focus areas. They describe the direction of the work, not a catalogue of finished commercial products.

01

Trading systems

Software architecture and components for systematic crypto trading, built to be tested in isolation.

02

Execution infrastructure

Exchange connectivity, authentication, order submission, position handling and execution workflows.

03

Backtesting & strategy engineering

Strategy implementation, historical simulation and the tooling to evaluate results honestly.

04

Risk & observability

Risk controls, trade logging, operational monitoring and visibility into system behavior.

Planned

AI-assisted development tooling

We plan to use language models to draft experiment specifications, review strategy code and explain test results. A language model will not compute results or place orders. Calculations stay in deterministic code, and a human reviews generated code before it runs.

Principles

How we build

Correctness before complexity

Build components that behave predictably and can be tested.

Risk-aware execution

Treat risk checks, order handling and failure scenarios as core engineering concerns.

Observable systems

Make system behavior easier to inspect, debug and understand.

Practical implementation

Prioritize working software, clear documentation and measurable progress.
